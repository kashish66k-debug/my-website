VASHORA website
----------------
1. Extract this ZIP file.
2. Open index.html in Chrome to preview the website.
3. To publish with GitHub Pages, upload index.html (and this README if you like)
   to the root of your GitHub repository.
4. In GitHub: Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.

Note: Tailwind CSS is loaded from its CDN, so an internet connection is needed
to load the styling when viewing the page.
The email address hello@vashora.com is sample content; replace it with your own.
